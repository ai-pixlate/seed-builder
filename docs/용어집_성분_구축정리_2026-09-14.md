## 2. 왜 식약처 API인가

- 이전 방식은 **올리브영 전성분 한글명 → 로마자로 되돌려 → 아마존 전성분 영문과 비슷한 것 찾기**였음. 소리가 비슷한 다른 성분이 붙거나(예: 글리세릴올리에이트 ↔ Glyceryl Laurate) 아마존에 없는 성분은 못 찾는 한계가 있었음.
- 식약처 사전은 한글 표준명 ↔ 영문명이 **공식적으로 정해져 있음**.
- 대한화장품협회 성분사전은 **라이선스 문제 우려로 사용하지 않음**. 공공데이터포털 API만 사용.

## 3. 구축 과정

### 3-1. 준비
- 공공데이터포털에서 API 활용신청 → 인증키 발급 (개발계정, 일일 10,000회, 활용기간 2026-09-14 ~ 2028-09-14)
- 인증키는 작업 폴더의 `.env` 파일에만 저장. 공유 문서·깃허브에 올리지 않음 (`.gitignore` 등록)

### 3-2. 응답 구조 확인 (1단계)
- 3건만 먼저 받아서 원문 확인
- 확인된 사항
  - 전체 건수 `totalCount` = 21,897
  - 한 번에 받을 수 있는 최대 건수 = **500건** (1,000건 요청 시 오류)
  - 1쪽과 2쪽이 겹치지 않음 → 쪽 넘기기 정상
- API가 주는 칸 5개

| API 칸 이름 | 뜻 | 예: 가지열매추출물 |
|---|---|---|
| INGR_KOR_NAME | 한글 표준 성분명 | 가지열매추출물 |
| INGR_ENG_NAME | 영문 성분명 | Solanum Melongena (Eggplant) Fruit Extract |
| CAS_NO | 국제 화학물질 번호 | 84012-19-1 |
| ORIGIN_MAJOR_KOR_NAME | 기원 및 정의 | 이 원료는 가지(Eggplant) Solanum melongena의 열매에서 추출한 것이다. |
| INGR_SYNONYM | 이명(다른 이름) | 가지추출물 |

### 3-3. 전량 수집 (2단계)
- 500건씩 44쪽, 약 41초 소요
- 요청 사이 0.4초 쉬기, 실패 시 최대 3번 재시도
- 중간에 끊겨도 이어받을 수 있게 진행 기록(체크포인트) 저장
- 받은 원본은 **가공 없이** `raw/mfds_raw.jsonl`에 보존 (덮어쓰기 금지)
- 검증: totalCount 21,897 = 실제 받은 건수 21,897 ✅ / 같은 표준명 중복 0건 ✅

### 3-4. 용어집 형식으로 옮기기 (3단계)
기존 `용어집_성분.xlsx` 「매칭후보」 탭과 **같은 열 순서·머리글 색**으로 만듦.

| 열 | 머리글 색 | 넣은 값 |
|---|---|---|
| 구역 | 회색 | 비움 (식약처 전량이라 A/B/C 구분 없음) |
| id | 남색 | **비움** — GL 번호는 검수 확정 후 부여 (번호 재사용 금지) |
| source_ko | 남색 | 식약처 한글 표준명, 원본 그대로 |
| target_text | 남색 | 식약처 영문명, 원본 그대로. 없으면 비움 (추측·번역으로 채우지 않음) |
| term_kind | 남색 | ingredient |
| enforcement | 남색 | 강제 (전 행) |
| target_lang | 남색 | en |
| internal_category | 남색 | common |
| example_sentence | 남색 | 비움 |
| frequency / corpus_size / corpus_version | 회색 | 비움 |
| verified_at | 남색 | **비움** — 검수자가 채움 |
| source | 회색 | 식약처 화장품 원료성분정보 API(15111774) |
| note | 회색 | 꼬리표를 ` / `로 이어 붙임 (아래 3-5) |
| version | 회색 | 1 |
| 이명 | 초록 | 식약처 이명 칸 원본 그대로 (검토용, 시드 전달 시 삭제) |

- 머리글 색 규칙: **남색 = DB로 가는 열 / 회색 = 시트 전용 / 초록 = 검토용**
- 검증: 한글명·영문명·이명 모두 원본과 한 줄씩 대조 → 다른 곳 0건 ✅

### 3-5. note 꼬리표
엑셀에서 `note` 칸을 거르기 해서 **"INCI 확인 필요"만 골라 검수**할 수 있게 함. 한 행에 꼬리표가 여러 개 붙을 수 있음. 세미콜론(;)은 시드 구분 기호라 쓰지 않음.

| 꼬리표 | 뜻 | 예시 | 건수 |
|---|---|---|---|
| 식약처 표준영문명 | 모든 행 기본 | | 21,897 |
| INCI 확인 필요: 영문명 여러 개 | 영문명 칸에 쉼표로 이름이 여러 개 → 대표 표기 선택 필요 | 정제수 `Water,Aqua` | 200 |
| INCI 확인 필요: 색소 CI 표기 | CI 번호가 붙은 것. INCI에서 색소는 보통 CI 번호가 공식 이름 → 표기 확인 | 황색4호 `Tartrazine,CI 19140` | 95 |
| INCI 확인 필요: 대문자 표기 | 전부 대문자인 이름이 섞인 것 (INCI는 보통 첫 글자만 대문자). PEG·TEA 같은 짧은 약어는 제외 | 마그네슘가루 `MAGNESIUM POWDER` | 13 |
| INCI 확인 필요: 영문명 없음 | 식약처에 영문명이 없어 INCI 여부 판단 불가 | 가공소금 | 1,273 |
| 규제 참고: … | 규제 관련 참고 메모. **enforcement에 영향 없음** — 판단은 규제집 | 아래 표 | 3 |

- "INCI 확인 필요" 꼬리표가 하나 이상 붙은 행: **1,483개**

규제 참고 3건

| 식약처 표준명 | note 내용 |
|---|---|
| 황색4호 | 착색제 — 미국 라벨은 FD&C Yellow No. 5 주표기, CI 번호는 괄호 병기로 알려짐, 규제집 확인 |

## 4. 주의해야 할 점

### ① INCI 사전과 직접 대조하지 않았음
- 영문명은 **식약처가 정한 이름**이고, 공식 INCI 사전과 한 줄씩 대조하지는 않았음
- 참고 근거: 기존 아마존 US 라벨 전성분(미국 라벨은 INCI 표기 의무)과 비교했을 때, 식약처 사전에서 찾은 202개 중 **181개가 글자까지 같았음**. 단 자주 쓰는 성분 위주라 전체 보증은 아님
- INCI와 어긋날 수 있는 곳은 note에 "INCI 확인 필요"로 표시 (3-5 참고)

### ② 영문명 칸에 이름이 여러 개 (200개)
- 예: 정제수 `Water,Aqua` / 금 `CI 77480,Gold` / 미네랄오일 `Mineral Oil,Paraffinum Liquidum`
- 그대로 쓰면 "Water,Aqua"가 통째로 들어감 → **어느 것을 쓸지 사람이 골라야 함**
- 단, `1,2-Hexanediol`처럼 양쪽이 숫자인 쉼표는 이름의 일부

### ③ 영문명 없는 성분 (1,273개)
- 예: 가공소금
- 식약처에도 영문명이 없어 빈칸 → 번역 시 용어집으로 못 채움

### ④ 표기 차이로 검색이 안 될 수 있음
- 식약처는 **옛 표기**가 섞여 있음: 에**칠**·메**칠**·**디** ↔ 올리브영 등은 에**틸**·메**틸**·**다이**
- 예: 에칠헥실트리아존(식약처) ≠ 에틸헥실트리아존(올리브영) → 글자가 달라 안 찾아짐
- **"용어집에 없다 = 없는 성분"이 아님**

### ⑤ 중복·충돌
- 거의 같은 이름 두 줄 1건: `나일론6/12`(Nylon 6/12) / `나일론-6/12`(Nylon-6/12)
- 같은 영문명에 한글명 여러 개 28건: 예) `Panax Ginseng Root` ← 인삼, 산양삼뿌리 → 영어→한국어 역방향 조회 시 하나로 안 정해짐
- 같은 이명이 서로 다른 성분 2개에 걸린 경우 66건: 예) 이명 "마카다미아씨오일" → 영문명 2개 → 이명으로 찾았을 땐 꼭 확인

### ⑥ 이명 칸
- 한 칸에 이름이 여러 개인 경우 146개 (쉼표로 구분)
- `/`는 이름의 일부 (예: 말로우꽃/잎/줄기추출물)
- 이명이 전부 옛 이름인지는 확인하지 않음
- 이명은 source_ko로 옮기지 않음 — 용어집 행은 전부 식약처 표준명 기준

### ⑦ 칸 안에 줄바꿈·공백 (시드로 옮길 때 표가 깨질 수 있음)
- 줄바꿈 든 값 5개: 해바라기씨왁스·그린와틀꽃왁스 영문명, 소듐아세틸에스에이치-올리고펩타이드-195… 한글·영문명, 아세틸트라이펩타이드-146
- 앞뒤 공백 붙은 이름 2개: 아세틸트라이펩타이드-146, 다이라우라미도아이소프로판올
- 원본 보존 규칙으로 손대지 않음 → 시드 전달 전 확인 필요
- 성분명·영문명 칸에 세미콜론(;) 든 행은 0건 ✅

### ⑧ 아직 DB에 들어갈 준비가 안 됨
- id·verified_at 전부 비어 있음 → 규칙상 시드에 안 들어감
- 초록 `이명` 칸은 시드 전달 시 삭제
