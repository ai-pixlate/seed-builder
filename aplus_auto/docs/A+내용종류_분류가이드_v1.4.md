# A+ 이미지 내용 종류 분류 가이드 (라벨 v1.4)

아마존 US 뷰티 베스트셀러 상품의 A+ 상세페이지 이미지(가로형 배너)를 한 장씩 보고 "무슨 내용을 담은 이미지인지" 라벨을 붙인다.

## 규칙
- **이미지가 글자로 말하는 내용(메시지)을 기준으로 판단한다.** 사진(질감 사진, 원료 사진, 제품 여러 개)은 보조 정보다. 예: 크림 질감 사진 + "deep moisture" 문구 → BENEFIT(TEXTURE 아님).
- 이미지마다 **주 라벨 1개**(가장 중심이 되는 내용) + **보조 라벨 0~2개**.
- **보조 라벨은 배지·별도 블록처럼 눈에 띄게 따로 있는 요소만** 붙인다. 문구 속 단어(smooth, hydrating, for all skin types 등)만으로는 보조 라벨을 붙이지 않는다. 대부분의 이미지는 보조 라벨이 없다.
- 이미지는 **한 장씩 독립적으로** 판단한다(앞뒤 이미지 맥락 무시).
- 판단이 정말 애매하면 OTHER로 두고 note에 이유를 쓴다.
- VARIANT면 옵션 종류(opt)를 "색상", "향", "타입·스타일" 중 하나로 적는다. 셰이드(밝기 단계 포함)·색 이름은 모두 "색상".

## 라벨 19개
| 코드 | 이름 | 정의 | 헷갈릴 때 |
|---|---|---|---|
| HERO | 제품 소개 | 제품(사진·이름)이 중심. 제품명·한 줄 소개, 또는 효능 한 줄까지. 글자 없는 제품 무드컷·모델+제품 컷 포함 | 효능 포인트 2개 이상 나열 → BENEFIT |
| BENEFIT | 핵심 효능·특징 | 효능·특징 포인트 2개 이상(아이콘·불릿·칸), 또는 효능 문구가 큰 글자로 주인공이고 제품은 보조 | 수치(%·시간 그래프)·전후 사진이 근거로 나오면 → PROOF |
| INGREDIENT | 성분·기술 | 글자가 특정 성분 이름·기술·작용 원리를 설명하는 이미지. 무첨가(free-from) 표시 포함 | 원료 사진 + 효능 문구 중심 → BENEFIT |
| PROOF | 효과 증명 | 전후 사진, 임상·소비자 조사 수치(92% agree, -40% 등) | 타사와 비교 → COMPARE |
| COMPARE | 비교 | 우리 제품 vs 타사·일반 제품(비교표 포함) | 같은 사람 사용 전후 → PROOF |
| HOWTO | 사용법 | 이 제품의 사용 단계(Step)·순서·팁·주기 | 다른 제품과 같이 쓰는 법 → ROUTINE |
| ROUTINE | 루틴·함께 쓰기 | 이 제품을 다른 제품과 **어떻게 같이 쓰는지**(순서·조합 설명이 중심) | 제품 여러 개를 보여주는 게 중심이면 'routine' 문구가 있어도 → LINEUP |
| LINEUP | 라인업 | 같은 브랜드의 제품 여러 개를 **보여주는** 이미지(컬렉션·패밀리·세트·"discover more") | 같은 제품의 색상·향 선택지 → VARIANT |
| VARIANT | 색상·옵션 | 같은 제품의 **선택지를 말하는** 이미지: 색 이름·셰이드 개수(예: 11 SHADES)·스와치·향 종류·스타일 종류, 선택지별 결과(머리색별 염색 결과) | 제품이 여러 색으로 늘어서 보이기만 하고 선택지 설명이 없으면 → HERO |
| TEXTURE | 제형·사용감·향 | 글자가 제형·바르는 느낌·향을 말하는 이미지(텍스처 사진만으로는 아님) | 질감 사진 + 효능 문구 → BENEFIT |
| FEATURE | 제품 디테일·구성 | 용기·어플리케이터·브러시·크기·구성품(박스 안 내용물) 같은 물리적 특징 | |
| TARGET | 추천 대상·사용 상황 | '이런 분께', 피부·모발 타입별 추천, 선물·여행 같은 사용 상황이 중심 | |
| PROBLEM | 고민 제시 | 소비자의 고민·문제를 먼저 꺼내는 내용이 중심 | |
| CERT | 인증·검증 | 인증·검증이 이미지의 **주된 메시지**일 때만: 인증 마크(vegan, cruelty-free, leaping bunny)·테스트 완료·특허·**피부과 관련 문구 전부**(dermatologist tested/developed/recommended)·검증·안전성 문구(clinically tested, gentle·safe)가 중심이거나, **동그란 배지 아이콘들이 주인공**인 이미지 | 성분·브랜드·효능을 설명하는 이미지에 배지가 붙어 있기만 하면 → 주 라벨은 원래 내용, CERT는 보조 · 효과 수치(%) → PROOF |
| SOCIAL | 신뢰·평판 | 리뷰 인용, 판매량·#1·베스트셀러, 수상, 언론 로고·인용, 인플루언서 | 피부과 관련 문구 → CERT · 효과 수치 → PROOF |
| BRAND | 브랜드 이야기 | 브랜드 철학·역사·창립자·가치(클린·비건·지속가능성) 설명 | 로고만 크게 → LOGO |
| LOGO | 브랜드 로고 띠 | 로고가 주인공이고 글자는 슬로건 한 줄 이하(모델·무드 사진 배경 가능) | |
| FAQ | 질문·주의 안내 | 자주 묻는 질문, 주의·안내(Notice), 정품 인증 안내 | |
| OTHER | 기타·판단 불가 | 어디에도 안 맞거나 애매함 | |

## 출력 형식
JSON 배열 하나. 이미지 위 노란 글자 ID(T001 등) 기준으로 한 줄씩:
`{"tid":"T001","label":"HERO","sub":["CERT"],"opt":"","conf":"high","note":""}`
- sub: 보조 라벨 배열(없으면 [])
- opt: VARIANT일 때만 값, 아니면 ""
- conf: "high" 또는 "low"(경계에 걸려 애매하면 low)
- note: low이거나 OTHER일 때 짧은 이유(한국어)
